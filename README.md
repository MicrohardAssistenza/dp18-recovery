# DP18 Recovery

Recovery automatico per macchine DP18/DD40 Microhard.

La release corrente e' la v1.3.0, basata sul flusso validato sul campo: conversione DD40 -> DP18 3.12, recupero matricola MH430, attesa conferma seriale prima del reboot MH430, ricostruzione prodotti e verifica finale.

Le credenziali operative non sono salvate nel repository: vengono passate al bootstrap e conservate solo localmente durante il recovery.
